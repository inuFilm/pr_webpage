# Morse Atelier

静的 HTML / CSS / JavaScript の英数字モールス練習アプリ。`index.html` をブラウザで開くか、サイトのツール一覧から起動します。ビルド・外部依存・通信は不要です。設定のみブラウザのlocalStorageに保存します。保存できない環境でも練習できます。

- 分岐図：左が短点、右が長点（パドルと同じ）。四角は長点、丸は短点。数字まで最大5段。クリック・Enterで選択し「選んだ文字を聴く」で再生。
- パドル：左が短点、右が長点。既定は18 WPMでホバー中に連打。72px幅・160px高のパドル間は18px。入るたびに1打にも切り替え可能。キーボードはF/J（同時保持は交互）。タッチは押している間が保持扱い。
- 初回の音声は「音を有効にする」かお手本再生で有効化。音が使えなくても入力可能。
- 確定は自動、またはEnter。空白はSpace。Backspaceで1つ戻す。Escape、非表示・フォーカス喪失で音と打鍵を停止（途中の符号を破棄）。5打を超えても音は継続し、解読は未定義として扱います。
- 正誤判定は文字ごと。間違えても課題は進まず、正しい文字で進む。空白も入力する。
- 文章は大文字化し、句読点や日本語を除去。変換後の課題を表示。練習内容は再読み込みでリセット。
- 音の比率は短点1、長点3、符号内休止1、文字間3、単語間7。打鍵の自動確定は設定値と3単位の大きい方。

検証：`node tools/morse/tests.cjs`。製品側に公開APIを作らず、テスト実行時だけクロージャにアクセスするDOMの軽量スタブと仮想時間で全36字、ホバー、連打、文章判定、停止、再生タイミングを検証。`browser-tests.cjs` は Playwright と Microsoft Edge（msedge）で実マウスのホバー、長時間保持、離脱、左右移動、自動出題、狭幅表示、設定の復元・不正データ・保存禁止環境を検証します。NODE_PATHにPlaywrightの所在を設定して実行。音声はAudioContextの有効化を検証し、聴感は自動検証の対象外。

文字練習は正解後350msで自動的に次の問題へ進みます。同じ文字の連続出題を避け、正解直後に打鍵した場合は即座に次の問題を開始します。モード切り替え・クリア・中断は予約済みの遷移を解除します。

保存対象：速度、文字の確定待ち、音量、パドル動作、出題範囲、符号ヒント、入力中文字表示、自動確定、地図の折りたたみ。キーは `morse-settings-v1`。入力文章・回答・音声の有効状態は保存しません。保存値の型・範囲・選択肢を検証し、不正値は既定値のままにします。
