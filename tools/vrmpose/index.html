    カメラ

    ガイド枠を100%未満にすると構図フレームが画面より小さく表示され、フレームの外側を見ながらポーズを調整できます。書き出しは枠の中身だけが写ります。
    「枠内をカメラの範囲にする」を ON にすると FOV(mm)がガイド枠基準になり、枠の外には画角の外側が表示されます(OFF のときの FOV は画面全体基準で、書き出しは実質より望遠になります)。

    キャラクター

      ポーズはモデルをまたいで共通形式で保存されるので、素体を差し替えても使い回せます。

      ボーン

      「＋カット」で現在の状態をカットとして追加。カットをタップで選択、キー(◆)を左右にドラッグでコマ数を調整、目盛りをドラッグでスクラブできます

      使い方

      画面の見方

      • 上のバーからすべての機能に入れます。ボタンを長押し(PCはマウスを乗せる)と説明が出ます
      • 左下のチップで操作するキャラを切り替え。右下には選択した関節のスライダーが出ます
      • 右上でイラスト⇔コンテのモード切替。↶↷でいつでも元に戻せます

      ポーズを付ける(基本)

      • 体の丸をそのままドラッグしてポーズを付けます。オレンジ(手・足)= IK: 引っ張ると肘・膝が自然についてきます
      • 水色 = 1関節ずつの回転(FK)
      • タップで選択(赤くなる)すると右下にスライダーが出ます。数値入力も可
      • 空きスペースをタップで選択解除。失敗しても ↶ で戻せます

      移動と向き

      • 黄色(足元)= キャラ全体をつかんで移動
      • ピンク(腰)= 足を床に残したまま腰だけ動く。しゃがみ・座りはこれで作ります
      • 緑(前方)= 円に沿ってドラッグでキャラの向きを回す

      細かい向き(緑・青の小玉)

      • 緑の小玉 = 捻る。円を描くようにドラッグ。手首=手のひらの向き、足首=つま先の向き、頭=顔の左右の向き
      • 青の小玉 = 向ける(LookAt式)。頭上の玉=うなずき・首上げ・傾げ、指先の先の玉=手先の向き。捻りは変わりません
      • 細かい角度は関節を選んで右下のスライダー(数値入力可)でも調整できます

      手と指

      • 手の関節(オレンジ)をタップ → 右下に「指を握る」「指を開く」スライダー
      • 選択中は指先に白い玉が出て、ドラッグで 1 本ずつ曲げられます
      • グー・チョキ・パー・指差し・👍 のプリセットは「ポーズ」パネルに(左右別)

      ポーズ・表情パネル

      • 上の「ポーズ」ボタンで開きます。立ち・座り・Tポーズから始めると早いです
      • 目線はカメラ目線 ON/OFF と上下左右。表情はスライダーで組み合わせられます
      • 効くのは選択中のキャラ(左下のチップで切替)です

      カメラと構図

      • 空きスペースを1本指ドラッグで回転、2本指で移動・ズーム(PCは右ドラッグ/ホイール)
      • 「カメラ」で FOV(mm換算)・平行投影・アスペクト比のガイド枠・書き出し解像度を設定
      • ガイド枠%を下げると枠が画面より小さくなり、枠の外を見ながら構図を作れます。PNG に写るのは枠の中だけ
      • オレンジの点線はアイレベル(カメラの高さ)。⚙ で非表示にできます

      モデルとシーン

      • ＋モデルから VRM(キャラ)・glTF/GLB(小物)・プリミティブ(立方体/球/円柱/板)を追加。複製は ⚙ のキャラクター欄
      • 小物の回転は三軸の玉を円周ドラッグ: 上=X(手前に倒す)、前=Y(向き)、横=Z(横に倒す)
      • 頭の関節を選ぶと「大きさ」で頭だけ拡縮(デフォルメ用)。ライトの向き・背景色は ⚙
      • 「シーン」で保存・.json 書き出し・新規シーン(すべてクリア)
      • モデルもポーズも端末の中だけに保存されます。外部には送信されません

      コンテモード(実験的)

      • 右上の「コンテ」でポーズ+カメラの状態をカットとして並べ、簡単な絵コンテが作れます
      • ＋カットで追加、帯をタップで選択・適用、「上書き」で差し替え
      • キー(◆)を左右ドラッグでコマ数調整、目盛りをドラッグでスクラブ、▶ で実時間再生
      • 連番 PNG(zip)で書き出して、そのまま編集ソフトでタイミング確認できます
