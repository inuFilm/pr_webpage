VRM Pose Ref 詳細マニュアル

1. はじめての5分

  1. 開くと素体が2体立っています。左下のチップ(素体A / 素体B)でどちらを操作するか選べます
  2. 手や足のオレンジの丸をドラッグしてみてください。肘・膝が自然についてきます(IK)
  3. 空いているところを1本指ドラッグするとカメラが回ります。2本指で移動・ズーム(PC は右ドラッグ / ホイール)
  4. 上の「ポーズ」から立ち / 座りのプリセットや手の形を選ぶと早く形になります
  5. できたら「PNG書き出し」。失敗しても ↶(元に戻す)でいつでも戻れます

4. ポーズを付ける(基本)

  • 体の丸をそのままドラッグしてポーズを付けます。タップすると選択(赤くなる)され、右下にスライダーが出ます
  • スライダーはひねり / 縦回転 / 横回転の絶対角。右端の数値欄に直接入力もできます
  • 空きスペースをタップで選択解除。↶ でいつでも戻せます

コツ

  • 大きな形はオレンジ(IK)で先に作り、細部を水色(FK)と緑・青の小玉で詰めるときれいに決まります
  • 足のオレンジをドラッグ中は足首の向きが保たれ、膝はつま先の方向に曲がります

5. 移動と向き

  • 黄色(足元): キャラ全体をつかんで移動。ポーズは崩れません
  • ピンク(腰): 足を床に置いたまま腰だけ動きます。両脚が自動で追従(IK)し、足首の向きも保たれます。しゃがみ・座りはこれで作るのが基本です
  • 緑(前方の玉): 足元の円に沿ってドラッグするとキャラの向きが回ります

6. 細かい向き(緑=捻る・青=向ける)

  • 緑の小玉 = 捻る。円を描くようにドラッグすると軸のまわりに回ります。手首=手のひらの向き、足首=つま先の向き、頭=顔の左右の向き。軸を真横から見ているときは、接線方向のドラッグ量で回ります
  • 青の小玉 = 向ける(LookAt式)。頭上の玉をドラッグ=うなずき・首上げ・傾げ。指先の少し先の玉=手先の向き。向けるだけなので捻りの角度は変わりません。緑と青で役割が完全に分かれています

7. 手と指

  • 手首のオレンジをタップして選ぶと、右下に「指を握る」「指を開く」スライダーが出ます
  • 選択中は指先に白い玉が現れ、1 本ずつドラッグで曲げ量を直接調整できます
  • グー / チョキ / パー / 指差し / 👍 のプリセットは「ポーズ」パネルに(左手・右手 別)

8. ポーズ・表情パネル

  • ポーズ: 立ち / 座り / Tポーズ。作り始めの土台に
  • 目線: カメラ目線の ON/OFF と、左右・上下の角度。眼球の振れ幅はモデル側の設定で 10° 前後に制限されるのが VRM の仕様です(控えめに見えるのは正常)
  • 表情: にこ・怒り・驚き…などをスライダーで組み合わせ
  • 効くのは選択中のキャラ(左下チップで切替)です

目線や表情が登録されていないモデル(この素体もそうです)では、該当セクションは自動的に表示されません。表示されない=そのモデルに機能が無い、という意味です。

9. カメラと構図 / PNG 書き出し

カメラ

  • FOV: 画角。フルサイズ換算の mm も併記されます。パースを弱くしたいときは FOV を小さく(望遠)、あおり・広角の迫力が欲しいときは大きく
  • 平行投影: パース無し。三面図的な資料に
  • アイレベル: カメラの高さの水平線がオレンジ点線で表示されます(⚙ で OFF 可)

構図ガイド

  • アスペクト比を選ぶと構図ガイド枠が出ます。書き出されるのは枠の中身だけ
  • ガイド枠% を下げると枠が画面より小さくなり、枠の外を見ながらポーズや配置を調整できます(セーフライン)
  • 枠内をカメラの範囲にする: ON にすると FOV(mm)が枠基準になります。OFF のときの FOV は画面全体基準なので、枠で切り出した分だけ書き出しは実質望遠になります。レンズ感を厳密にそろえたい人は ON に

10. PNG 書き出し

  • 「PNG書き出し」を押すと、ガイド枠の範囲が指定解像度(カメラ → 書き出し長辺 px)で書き出されます
  • 保存先は、保存先を選ぶダイアログ(PC の Chrome / Edge など)→ 共有シート(iPad)の順で開きます
  • ⚙ の「確認なしで直接ダウンロード」を ON にすると、ダイアログを出さず即保存します
  • ⚙ の「PNGを透過背景にする」で背景を透明にできます(Procreate に重ねる用)

11. モデルとシーン

モデルの追加

  • ＋モデル → ファイルを読み込み: VRM(0.x / 1.0 両対応)はキャラとして、glTF / GLB は小物として配置されます
  • プリミティブ(立方体 / 球 / 円柱 / 板): あたりや小道具のスタンドインに。シーン保存にも対応
  • 複製・ミラー・リセット・削除は ⚙ のキャラクター欄から

小物の操作(三軸コントローラー)

  • 紫 = 移動、上の赤 = X回転(手前に倒す)、前の緑 = Y回転(向き)、横の青 = Z回転(横に倒す)。玉を円を描くようにドラッグ
  • 回転はワールド軸基準なので、どれだけ回しても玉の位置は変わりません。細かい角度は選択して右下のスライダーでも

そのほか

  • 頭部の大きさ: 頭の関節を選ぶと「大きさ」スライダーが出ます。頭だけ拡縮(デフォルメ用)
  • ライト: ⚙ → ライト(平行光の向き)を XYZ 回転で調整。リセットボタン付き
  • シーン保存: 「シーン」→ 名前を付けて保存 / .json 書き出し・読み込み。ポーズ・カメラ・小物・設定・コンテのタイムラインが入ります。モデル本体は含まれないので、別端末ではモデルを読み込み直すと復元されます
  • ポーズはモデルをまたいで共通形式で保存されます。素体で作ったポーズを本番モデルにそのまま使えます

12. コンテモード(実験的)

  • 右上の「コンテ」で切替。カット = 今のポーズ + カメラ + 小物のスナップショットです(補間はしません)
  • ＋カットで追加 → 帯をタップで選択・その状態が適用されます。「上書き」で今の状態に差し替え、◀▶で並び替え
  • キー(◆)を左右にドラッグでそのカットのコマ数を調整。目盛りをドラッグでスクラブ、数値欄でも指定できます
  • 24 / 30 fps を選んで ▶ 再生(実時間)。連番書き出しで全コマの PNG が zip になります。ホールド分も複製されるので、編集ソフトに読み込むだけでタイミング確認できます
  • タイムラインはシーン .json に含まれます

13. iPad で使う

  1. Safari でこのツールの URL を開く
  2. 共有 → ホーム画面に追加。全画面になり、オフラインでも起動でき、保存データも消えにくくなります
  3. Procreate と Split View で並べて、ポーズ資料として使うのがおすすめの使い方です
  4. VRM の読み込みは iCloud Drive /「ファイル」経由でできます

14. こまったとき

目線・表情の項目が無いそのモデルに目線(目ボーン)や表情が入っていません。故障ではありません
ポーズが崩れた・戻したい右上の ↶ で戻せます。最初からやり直すなら「ポーズ」→ 立ち / Tポーズ
書き出した絵の範囲が違う書き出されるのはガイド枠の中身です。「カメラ」でアスペクト比とガイド枠%を確認してください
更新したはずが古いままオフライン用のキャッシュが効いています。アプリを一度閉じて開き直すと裏で更新され、次の起動で新しくなります
モデルを間違って消したモデル本体は端末内のみ保存です。＋モデルから読み込み直してください。ポーズはシーンに保存していれば復元できます
動きが重い⚙ で「操作ハンドルを表示」を一時 OFF にする、キャラ数を減らす、などで軽くなります
