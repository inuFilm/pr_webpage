# 撮影処理学習処

キャラと背景の色・明暗・光・縁を試す2Dラボと、Part 0〜2の教科書14章。`docs/web/COMPOLAB_SPEC.md` の **Phase 1** を実装しています。

## 起動

`serve.bat` を実行するか、リポジトリのルートから次を実行します。ビルドや npm install は不要です。Python 3 はローカル配信用だけに使います。

```powershell
python tools/compolab/serve.py
```

[ローカルのラボ](http://127.0.0.1:8771/tools/compolab/) が開きます。使用中なら `--port 8772`。自動で開かない場合は `--no-browser`、停止は Ctrl+C。ES modulesと画像の読み込みのため、fileの直開きではなくHTTPで開いてください。`mk hub` にも登録済みです。

サンプルを選ぶ →「背景に合わせる」→ 各段をON/OFF → A/B比較 → スコープの対象をキャラ・背景に切り替える、の順で試せます。教科書の「ラボで試す」はUndo一回で元の作業に戻せます。

## 実装範囲

- PNG/JPEG/WebPのキャラ・背景・前景読み込み、ドラッグ＆ドロップ。画像は端末内だけで処理し、同梱ファイル以外への通信はしません。
- 画像・単色・パラ・調整・グループ。並べ替え、複製、グループ化、表示切替、単独表示、変形、16種類のブレンド、不透明度、クリッピング、アルファ／輝度／グラデーション／矩形マスク。
- WebGL2、RGBA16F、premultiplied alpha、リニア／ガンマ。float FBO非対応時はRGBA8へ落とし「HDR不可」を表示。WebGL2自体がなければ起動できない理由を表示します。
- 色調整（露出、近似WB、コントラスト、ASC CDL、Oklab彩度・色相）、統計マッチ、明暗の範囲、ぼかし、グロー、ディフュージョン、ライトラップ、エッジぼかし、空気感、グレイン、ビネット。
- 背景合わせは編集できるグループとキャラの効果を作成。背景全体／背後、段の選択、全体の強さ、実測レポート、重複防止、Undo。
- ヒストグラム・波形・ベクトルスコープ、対象別の前スナップショット、A/Bスライダー・長押し比較。
- PNG合成、処理後の透明キャラPNG、シーンJSON、レポートTXT。画像本体はJSONやlocalStorageに入れず、再開時は元画像の再読み込みを案内。同名画像の置換でもUndo用の旧テクスチャを保持します。
- 履歴100件、ドラッグ中は一回のUndo。Ctrl+Z／Ctrl+Shift+Zはテキスト入力と競合させません。ホイールズーム、ビューにフォーカスしてSpace＋ドラッグ、0で全体表示。ボタンの代替操作もあります。
- 900px未満ではパネルをタブ切替。保存禁止環境でも作業でき、保存不可の表示を継続します。
- 共通LessonState、理解チェック14問、本文・図・実験プリセット14本。進捗は `compolab-done-v2`、章IDは `compolab-<slug>`。

画像素材は、今回のユーザー指定により内蔵 **image_gen** で新規生成しました。透明キャラ `assets/sample_char.png` は1024×1536、背景 `day.png` / `sunset.png` / `night.png` / `rain.png` は各1672×941。生成されたアルファを変更せず保存しています。全プロンプトは **`assets/prompts.json`**。モデルや画像を入力して生成したものではありません。

図の模式図はcanvas、背景・キャラの絵は生成PNGです。素材を再生成するときは目視後に `tests/samples.json` のSHA256・固定3画素を確認して更新し、ブラウザ検証を実行してください。

効果の式を変更する際はCPU版とGLSL版の両方を読みます。非分離ブレンドはW3Cの輝度係数（0.3/0.59/0.11）、統計にはRec.709とOklabを使用します。

- [W3C Compositing and Blending Level 1](https://www.w3.org/TR/compositing-1/)
- [Oklabの原論文・実装](https://bottosson.github.io/posts/oklab/)

## 設計書から変えた点

1. 追加指定により、VRM書き出しキャラ／シェーダー背景を生成PNGへ変更。再現性は固定画素とSHA256で担保し、サンプルの合成寸法1920×1080は維持。
2. §8.3の記載式はstrength=0で元画素が平均色に潰れるため、`mix(in, mapped, strength)` に修正。倍率0.5〜2制限は維持。制限外のstd完全一致より破綻防止を優先することを教材にも明記。
3. 透明グループに環境色・調整を入れるだけではキャラ自体を調整できないため、背景合わせだけに `params.baseLayer` を追加。そのキャラを入力とする独立グループとして処理し、半透明のアルファを二重に掛けず一度だけ合成。移動・複製・グループ化はキャラと一緒に行います。
4. 百分位の幅合わせが目標の平均を通り越す場合、明暗の強さを0.5以下に制限。夕方は0.16146。値と理由をレポートに表示し、後から編集可能。
5. 木の葉や舗装の模様をノイズと混同して過剰な粒子を付けないよう、自動グレインを0.015以下に制限。手動効果の上限は変更していません。
6. PNGはCanvas 2Dの丸めを避け、RGBA8画素をCompressionStreamで直接保存。作業解像度の初期値は反応速度を優先して1024、設定で2048／元の解像度。書き出しは長辺4096まで。
7. FBOはサイズ別の再利用プール。ぼかしは半解像度鎖＋分離ガウス、グローは狭い半径と広い半径を重ねます。統計・スコープは現在の変形・効果を反映したRGBA8を長辺256で読みます。
8. 本文ではアプリ名だけで色管理の既定値を断定せず、実際の作業空間によって変わることを説明。
