Pyro のノード — どれが何をするのか

houdini-nodes / 2026-08-19

出典: SideFX 公式ドキュメント Pyro (Houdini 公式) / Pyro Solver SOP / Volumes。 このページは上記を日本語で要約・再構成した学習メモです。ノード名とパラメータ名は Houdini 22.0.368 の同梱ヘルプと実機で照合しています。

この記事で扱うこと

  • Pyro が5段でできていること、どの段にどのノードが属するか
  • 発生源・焼き込み・ソルバ・後処理・ボリューム操作を1ノードずつ
  • 各ノードの要のパラメータ（名前は実機で照合済み）

まず、Pyro は5段でできている

ノードの数は多いのですが、並び方はいつも同じです。 どのノードも、この5段のどこかに属しています。

段やること代表ノード
1. 発生源「どこから」「何が」出るかを点で決める pyrosource / pyroburstsource
2. 焼く点をボリュームに変換する volumerasterizeattributes
3. 解くボリュームを時間方向に解く pyrosolver
4. 見た目温度を炎の色にする / レンダー用の属性に焼く pyropostprocess / pyrobakevolume
5. ボリューム操作できたボリュームを加工する（どの段でも使う） volumeblur / volumewrangle ほか

2段目が要ります。ソルバはボリュームしか受け取れないので、 点のまま pyrosolver に差しても何も起きません。ここを飛ばすのが最初のつまずきどころです。

1. 発生源をつくる（点をつくる段）

ここで作るのは点です。density や temperature を点属性として持たせておき、次の段でボリュームに焼きます。

Pyro Source pyrosource

やること入力の形から、Pyro の発生源になる点を作る
使いどころ煙・炎を出したいものが決まったら、いちばん最初に通すノード
入力1〜2
要のパラメータinitialize — 使い道のプリセット。ここを選ぶと下のパラメータ一式が切り替わる（既定 0）
mode — 点をどう作るか。表面に撒く / 体積に撒く / 入力の点をそのまま使う（既定 1）
particlesep — 点の間隔。この値がそのまま発生源の細かさになる（既定 0.1）
particlescale — 点の大きさ。pscale は particlesep × particlescale になる（既定 2）
attributes — density / temperature など、点に持たせる属性の並び

出てくるのは点であってボリュームではありません。density や temperature を点属性として持っています。この後に焼く段が必ず要ります。

公式リファレンス（英語）

Pyro Burst Source pyroburstsource

やること一瞬だけ出る発生源の点を作る
使いどころ爆発・銃口炎・衝撃波・爆轟リング。出続けないものはこちら
入力0〜1
要のパラメータshapetype — 発生源の形。球 / リング / 線など（既定 0）
size — 大きさ（既定 1）
dir — 向き。銃口炎のように方向のあるものはここ（既定 0.0 1.0 0.0）
spreadangle — 広がりの角度。0 に近いほど細く飛ぶ（既定 90）
copynum — いくつ出すか（既定 5）

pyrosource との違いは時間の扱いです。あちらは出し続ける前提、こちらは1回で終わる前提で作られています。

公式リファレンス（英語）

Pyro Trail Source pyrotrailsource

やること爆発から尾を引く発生源の点を作る
使いどころ爆発の破片が煙を引きながら飛んでいく表現
入力1
要のパラメータquicksetups — 用途別のプリセット（既定 0）
guidepath — 尾の経路になるカーブ

経路のカーブは pyrotrailpath で作ります。2つで1組のノードです。

公式リファレンス（英語）

Pyro Trail Path pyrotrailpath

やること尾を引く経路になるカーブを作る
使いどころpyrotrailsource に渡す経路がほしいとき
入力0〜1
要のパラメータshapetype — 経路の散らし方（既定 0）
dodirnoise — 経路の向きにノイズを入れて真っ直ぐさを崩す（既定 False）

公式リファレンス（英語）

Pyro Scatter from Burst pyroscatterfromburst

やることburst の点のまわりに、雲のように点をばらまく
使いどころ爆発の煙を厚くしたいとき、粒っぽさを足したいとき
入力0〜1
要のパラメータshapetype — 撒く形（既定 0）
donoiseprune — ノイズで間引いて、均一さを崩す（既定 False）

公式リファレンス（英語）

Pyro Source Spread pyrosourcespread

やること点群の上を炎が広がっていく様子を解く
使いどころ紙・布・草が端から燃え広がる表現
入力1
要のパラメータburnrate — 燃える速さ（既定 0.5）
fuel_initial — 最初に持っている燃料の量（既定 0）
igniteattrib — 火が点いたことを表す属性の名前（既定 ignite）
coolingrate — 冷める速さ（既定 0.8）

これ自体がソルバです（フレームを進めながら解きます）。出てくるのは「いつ燃え始めたか」を持った点で、それを発生源として次の段に渡します。

公式リファレンス（英語）

Pyro Thruster Exhaust pyrothrusterexhaust

やることシミュレーションせずにノズルの噴射を作る
使いどころロケット・ジェットの定常的な噴射。解かないので巻き戻しが自由
入力0〜1
要のパラメータlength — 噴射の長さ（既定 1）
thickness — 太さ（既定 0.25）
noisestrength — 揺らぎの強さ（既定 1）
speed — 流れる速さ（既定 10）
注意ソルバを通さないので待ち時間がありません。定常的な噴射ならまずこれを試す価値があります。

公式リファレンス（英語）

Pyro Spawn Sources pyrospawnsources

やることパックした発生源セットを配るための、種になる点を作る
使いどころ同じ爆発を大量にばらまきたいとき（packed source set の入口）
入力0〜1
要のパラメータstartframe — 出し始めるフレーム（既定 1）
sourcespeed — 湧く速さ（既定 1）

公式リファレンス（英語）

Pyro Source Instance pyrosourceinstance

やること種の点から、実際に差し込む発生源のインスタンス点を作る
使いどころpyrospawnsources の次に置く
入力2
要のパラメータreferenceframe — 基準にするフレーム（既定 1）

公式リファレンス（英語）

Pyro Source Pack pyrosourcepack

やることボリュームをまとめて1つの「発生源セット」にパックする
使いどころ使い回す発生源を作っておくとき
入力0〜1
要のパラメータframerange — パックに含めるフレーム範囲（既定 1.0 12.0）
voxelsize — パックするボリュームのボクセルサイズ（既定 0.1）

pyrospawnsources / pyrosourceinstance / pyrosourcepack の3つで1組です。同じ爆発を何十個も配るときだけ出番があります。

公式リファレンス（英語）

2. ボリュームに焼く（ここを飛ばすと動かない）

ソルバはボリュームしか受け取れません。前の段で作った点をボリュームに変換します。

Volume Rasterize Attributes volumerasterizeattributes

やること点の属性を VDB に焼く
使いどころPyro の標準ルート。pyrosource の次はほぼこれ
入力1
要のパラメータattributes — 焼く属性の名前。density temperature のように並べる
voxelsize — ボクセルの大きさ。ソルバ側と揃える（既定 0.1）
particlescale — 点の影響半径の倍率。小さいと粒が分離して見える（既定 1）
velocityblur — 点の v を使って、動きの方向に伸ばして焼く（既定 False）
注意ボクセルサイズをソルバと揃えること。別々に持っているので、片方だけ変えると発生源が粗いまま（または無駄に細かいまま）になります。

公式リファレンス（英語）

Volume Rasterize Particles volumerasterizeparticles

やること点群をボリュームにする
使いどころ属性の細かい制御が要らない、単純な焼き込み
入力2
要のパラメータparticlescale — 点の影響半径（既定 1）
densityattrib — 密度に使う属性名（既定 density）
velocityblur — 速度方向に伸ばす（既定 False）

公式リファレンス（英語）

Volume Rasterize Curve volumerasterizecurve

やることカーブをボリュームにする
使いどころ線に沿った煙や炎の帯を作りたいとき
入力0〜3

公式リファレンス（英語）

3. 解く

Houdini 20 以降、Pyro は SOP の pyrosolver 1個で完結します。DOP を開く必要があるのは、微調整のために中の部品を差し替えたいときだけです。

Pyro Solver (SOP) pyrosolver

やることPyro を解く。中に DOP ネットワークを持っている
使いどころ煙・炎を解くときの本体。まずこれを置く
入力1〜2
要のパラメータdivsize — ボクセルサイズ。計算時間の主犯。まず粗く当たりを見る（既定 0.1）
substep — サブステップ。速い動きで破綻するとき上げる（既定 1）
opencl — GPU で解く（既定 False）
col_divsize — コリジョンのボクセルサイズ。divsize と連動しない（既定 0.1）
clampsize — 解く領域の上限を設ける（既定 False）
cacheenabled — メモリ上のキャッシュ（既定 True）
注意col_divsize は既定のままだと divsize と食い違います。本体を細かくしてもコリジョンが粗いままだと、発生源が壁に埋もれて煙が消えます。

公式リファレンス（英語）

DOP Network dopnet

やることシミュレーションの中身を入れる箱
使いどころソルバ・力・コリジョンを自分で組みたいとき
入力0〜4
要のパラメータcacheenabled — メモリキャッシュを使う（既定 True）
cachemaxsize — キャッシュの上限（MB）（既定 5000）
cachetodisk — ディスクに逃がす（既定 False）

SOP から見ると1ノードですが、中は別世界です。pyrosolver SOP も中身はこれです。

公式リファレンス（英語）

Pyro Solver (DOP) pyrosolver

やることDOP の中に置く Pyro のソルバ本体
使いどころSOP 版では届かないところを触りたいとき
入力1〜5

SOP 版の pyrosolver はこれを内側に持っています。先に SOP 版で足りるか確かめてから降りてくるほうが早いです。

公式リファレンス（英語）

Smoke Object smokeobject

やることDOP の中で「煙のオブジェクト」を定義する
使いどころ解く対象の器（フィールドの入れ物）を用意するとき
入力0

公式リファレンス（英語）

DOP Import Fields dopimportfield

やることDOP の中のフィールドを SOP 側に取り出す
使いどころDOP で解いた結果を SOP で加工したいとき
入力0

公式リファレンス（英語）

4. 見た目にする

解いた直後のボリュームは、密度と温度が入っているだけです。炎の色は自動では付きません。

Pyro Post-Process pyropostprocess::2.0

やること解いた結果に後処理をかける。温度から炎のフィールドを作るのが主な仕事
使いどころソルバの直後。ここを切ると煙だけになる
入力1
要のパラメータflamedensity — 炎として扱う密度のしきい値（既定 0.0001）
conv_vdb — VDB に変換する（既定 False）
conv_usefp16 — 16bit で持つ。容量が半分になる（既定 False）
bind_density — 密度フィールドの名前（既定 density）
bind_flame — 炎フィールドの名前（既定 flame）

公式リファレンス（英語）

Pyro Bake Volume pyrobakevolume

やることレンダーとビューポート用に、見た目のパラメータをボリュームに焼き込む
使いどころルックを決める段。散乱・煙の色・影の濃さはここ
入力1
要のパラメータdensityscale — 密度の倍率。濃さの主役（既定 1）
smokecolor — 煙の色（既定 1.0 1.0 1.0）
enablescatter — 散乱を有効にする。火の芯の明るさが変わる（既定 False）
maxres — ビューポート表示用の解像度上限（既定 128）
shop_materialpath — 使うマテリアル（既定 matnet/Pyro_Shader）

公式リファレンス（英語）

Volume Visualization volumevisualization

やることビューポートでの見え方だけを変える
使いどころ数値を確かめたいとき。レンダーには影響しない
入力1
要のパラメータvismode — 表示のしかた（既定 1）
rangemin — 表示する値の下限（既定 0）
rangemax — 上限（既定 1）
densityfield — 密度として表示するフィールド（既定 density）
emitfield — 発光として表示するフィールド

公式リファレンス（英語）

5. ボリュームを触る（どの段でも使う道具）

Pyro 専用ではありませんが、Pyro を触っていると必ず出てきます。

やることボクセル1つずつに VEX を書く

詰まりやすいところ

症状まず見るところ
何も出ない点のまま pyrosolver に差していないか。 焼く段（volumerasterizeattributes）が要る
煙は出るが炎が無いpyropostprocess を通しているか。 温度から炎を作るのはこのノード
細かくしたのに変わらないcol_divsize。 コリジョン側は divsize と連動しない
発生源のあたりで煙が消える同上。粗いコリジョンに発生源が埋もれている
煙が箱で切れるvolumeresize、または解く領域の上限 （clampsize / maxsize）
粒々に見える焼くときの particlescale。 小さすぎると点が分離して見える
