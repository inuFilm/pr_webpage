Houdini 22 入門 5 — Quick Surface Material でテクスチャを割り当てる

houdini / 2026-08-24

出典: H22 Foundations | Model Render Animate 5 | Solaris: Materials （SideFX 公式チュートリアル H22 Foundations: Model, Render, Animate の第5回 / Houdini 22 / 10:24 / 英語）。 このページは、上記の動画を見ながら自分用にまとめた日本語の学習メモです。SideFX 公式の翻訳ではありません。 前回はSolaris に持ち込んでカメラとライトを置くでした。

この回で扱うこと

  • Quick Surface Material を2つ作って、ボールと背景に割り当てること
  • マテリアルは作っただけでは何も起きないこと。割り当てるのは Material Linker の仕事です
  • この回いちばんの落とし穴 — Material Linker に表示フラグを立てるとカメラとライトが消えます
  • テクスチャ4枚（color / reflect / roughness / normal）の入れ方と、パスを $HIP/tex/… で書くこと
  • 背景のテクスチャが繰り返してしまう問題を UV Project で直すこと
  • Render Gallery でスナップショットを A / B 比較し、ネットワークの状態ごと戻せること

1. Quick Surface Material を2つ置く

ネットワークのいちばん上（背景とボールより前）に Tab から Quick Surface Material を置いて soccerball_mat と名付けます。 それを Alt + ドラッグで複製して backdrop_mat にし、それぞれを繋ぎます。

まず背景のほうだけ色を触ります。動画では緑にして少し暗く落としています。 ボール側はこの時点では何もしません。

Quick Surface Material とは何なのか

名前から「簡易マテリアル」に見えますが、中身はけっこう考えて作られたものです。 公式ヘルプによると、VOP でシェーダーを組むのではなく、Houdini に同梱された USD ファイルを参照する仕組みになっています。

性質意味
ベースMaterialX Standard Surface と PBR Texture Set
クック参照するだけなので速い。Material Library の中で VOP を USD に変換する手間がありません
メモリインスタンス間でデータを共有するので USD 側のオーバーヘッドが小さい
Karma XPUシェーダーモデルが固定なので、GPU 側のシェーダー再コンパイルが減ります
テクスチャ内部で MtlX Image を使い、パラメータごとに signature があらかじめ設定済みです

この「signature が設定済み」というのが地味に効いています。 roughness や metalness のような float のパラメータには float のマップ、 色のパラメータには color3 のテクスチャが割り当たるようになっていて、 ノーマルマップだけは vector3 として raw で読まれます。 だから後述のバンプの欄にノーマルマップを入れて、そのまま意図通りに効きます。

2. Material Linker で割り当てる

マテリアルを2つ置いてもビューは何も変わりません。まだ割り当てていないからです。 Tab から Material Linker を置きます。

ここで表示フラグの場所に注意します。Material Linker に表示フラグを立ててしまうと、 そこより下流にあるカメラもライトも全部消えます。 表示フラグはチェーンのいちばん下に置いたままにして、 Material Linker のパラメータだけを触るのが正しい進め方です。

LOP のネットワークは上から下に積み上がるので、「見ている場所」＝「そこまで積んだ状態」になります。 SOP でも同じ理屈ではあるのですが、Solaris だとライトやカメラまで消えるので影響が大きく感じられます。

割り当ての操作

  1. Material Linker の中でジオメトリのツリーを開きます（backdrop と soccerball_geo が並びます）
  2. マテリアルをリストにドラッグし、そこにジオメトリをドラッグします

背景に backdrop_mat を当てると緑になり、割り当てが効いたことが目で分かります。 ボールのほうは色を触っていないので、少しツヤが出るくらいの変化です。 このツヤで「ライトが少し強すぎるかも」と気づける、という進み方も参考になります。

3. テクスチャを4枚入れる

soccerball_mat に戻ってテクスチャを入れていきます。 各項目の set or create を押すと、まず既定の UV グリッドが入るので、 それをボタンから実ファイルに差し替えます。

項目入れるもの効果
Color → Color Map$HIP/tex/soccerball_color白黒のパッチの絵が乗ります
Specular Colorreflect マップ強すぎたスペキュラのハイライトが落ち着きます
Roughnessroughness マップ場所ごとのざらつきの差が出ます
Bumpnormal マップ（強さ 0.5）革の細かい傷や凹凸が出ます

パスを $HIP/tex/… で書けるのは、レッスン1で Set Project をやっておいたおかげです。 ここで効いてきます。

寄って見ると、ノーマルマップを入れたことで表面の傷が感じられるようになります。 強さ 0.5 くらいで十分効くようです。

テクスチャの欄の横にある COP のボタンを押すと、そのパラメータを COP で作るためのネットワークが作られます。 すでにマップが入っている場合は、そのファイルを読み込んだ File COP が用意されるので、画像処理を足せます。 このコースでは使いませんが、覚えておくと使いどころがありそうです。

ロゴの位置をずらす

テクスチャを貼ってみると、ロゴの位置が思ったところに来ないことがあります。 その場合はボールを選んで R で回します。 このときチェーンの下のほうに変換用のノードが作られるのですが、 それを掴んでボールの直後に差し込み直すことができます。 「実際に動かしたのはボールなのだから、ボールの近くに置く」という整理です。 バイパスすれば前後を比べられます。

4. 背景のテクスチャが繰り返してしまう問題

背景にもテクスチャを入れます。色を 1, 1, 1 に戻してから Color Map に $HIP/tex/backdrop_color を、Specular にも backdrop の reflect を入れます。

ところが絵が繰り返して並んでしまいます。1枚で全体を覆ってほしいのに、 タイル状になってしまう状態です。原因は背景の UV です。 Grid には最初からある UV がそのまま残っていて、狙った範囲になっていません。

直し方は Solaris 側ではなく、SOP に戻って背景の Grid のところで直します。

ノードパラメータ値
uvprojectvrange — V Range-1 を入れて V 方向を反転させます

V Range は「投影ジオメトリ上でテクスチャの下端と上端がどこに来るか」を決めるパラメータです。 ここを反転させることで、1枚のテクスチャが背景全体を覆う形になります。 Solaris に戻ると、繰り返しが消えて狙った見た目になっています。

見た目の問題を見た目のある場所（Solaris）で直そうとすると迷子になりがちですが、 UV の問題は UV を作った場所（SOP）に戻るのが早い、という良い例だと思います。

5. Render Gallery で比べて、戻す

ここからが便利な機能の紹介です。スナップショットを撮って、 Render Gallery で並べて比べられます。

  1. 今の状態でスナップショットを撮ります
  2. Light Mixer をバイパスして、もう1枚撮ります
  3. Render Gallery で片方を A、もう片方を B に設定して見比べます

動画では「バイパスしたほうが明るいけれど、Light Mixer を通したほうのトーンが良い」という判断をしています。 判断そのものより、この比べ方ができることがここでの学びだと思います。

そしてもう一段便利なのが、ギャラリーの画像を右クリックして revert network を選ぶと、 その絵を出したときのネットワークの状態に戻ることです。 バイパスを切っていたなら、それも含めて戻ります。

つまり設定を変えながらスナップショットを撮り溜めておけば、 後から気に入ったものを選んでネットワークごと復元できます。 探りながら進める作業では、かなり効くやり方だと思います。

この回のまとめ

  • Quick Surface Material は VOP で組むものではなく、同梱の USD を参照する仕組みです。クックが速く、Karma XPU のシェーダー再コンパイルも減ります
  • パラメータごとにテクスチャの signature が設定済みで、ノーマルマップは vector3 として raw で読まれます
  • マテリアルは作っただけでは何も起きません。Material Linker で割り当てて初めて効きます
  • Material Linker に表示フラグを立てるとカメラとライトが消えます。表示フラグはチェーンの最後に置いたままにします
  • テクスチャのパスは $HIP/tex/… で書けます。レッスン1の Set Project がここで効きます
  • 背景のテクスチャが繰り返すのは UV の問題です。SOP に戻って uvproject の V Range を反転させて直します
  • Render Gallery は絵を比べるだけでなく、ネットワークの状態ごと戻せます（右クリック → revert network）

次の第6回はシリーズ最長の27分で、場所も変わります。 ボールにスケルトンを入れてキャプチャし、APEX のセットドリブンキーで スクワッシュ＆ストレッチを仕込んで、リグを1つのアセットに固めるところまでやります。
