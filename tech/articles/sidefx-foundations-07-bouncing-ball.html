Houdini 22 入門 7 — バウンシングボールをアニメートする

houdini / 2026-08-24

出典: H22 Foundations | Model Render Animate 7 | Animate a Bouncing Ball （SideFX 公式チュートリアル H22 Foundations: Model, Render, Animate の第7回 / Houdini 22 / 9:33 / 英語）。 このページは、上記の動画を見ながら自分用にまとめた日本語の学習メモです。SideFX 公式の翻訳ではありません。 前回はAPEX でスクワッシュ＆ストレッチを仕込むでした。

この回で扱うこと

  • フレーム範囲を先に決めてしまうこと（1〜120）
  • 先にキーだけ並べて、後で高さを付けるという進め方
  • 着地を鋭くするためにタンジェントを切ること。ここが「浮いて見える」原因への対処です
  • キーをまとめて時間方向に縮めてテンポを上げる操作
  • モーションパスをバインドして、軌跡の上で直接バウンスを調整すること
  • 前回作った squash control を使って、落下で伸び・着地で潰れる動きを付けること
  • USD として書き出すところまで

1. フレーム範囲を決める

グローバルアニメーションオプションを開いて、範囲を 1〜120 にします。 既定の 240 フレームは要らないので、先に切ってしまいます。Apply して Close します。

タイムラインの表示が更新されるので、以降の作業がこの範囲で収まります。 アニメーションを始める前に尺を決めておくのは、地味ですが効きます。

2. まずキーを並べる

Enter で Pose ツール（アニメートステート）に入ります。 Shift + F1 でヒントを消しておきます。

動かすのは root です。前回リミットを入れておいたので、 横に流れることも高すぎるところまで行くこともありません。

  1. フレーム 1 でキーを打ちます
  2. フレーム 120 で K を押し、前進の値を 30 にします
  3. この時点でスクラブすると、ボールが転がって進みます（前回の Set Driven Key が効いています）
  4. バウンスが起きる位置に中間キーを足します。15 / 25 / 35 / 40 / 45

この段階では中間キーは全部同じ値なので、見た目は何も変わりません。 先に「どこで跳ねるか」だけを決めて、高さは後から付けるという段取りです。 これは考え方として真似しやすいなと思いました。

高さを付ける

フレームやること
1ボールを高く持ち上げます。ここから落ちてきます
25持ち上げます。1回目より低くします
40さらに小さく持ち上げます

これで「ボン、ボン、ボン」と跳ねながら減衰していく形になります。 再生が速すぎる場合はリアルタイム再生のオプションをオンにします。

後半はほぼ転がっているだけなので、タイムラインの表示範囲を 60 くらいに絞ると、 跳ねている部分に集中して判断できます。

3. 着地を鋭くする — タンジェントを切る

この時点では「跳ねている」より「浮いている」ように見えます。原因はカーブです。

アニメーションエディタで translate Y を選んで H を押すと、そのカーブが見えます。 各キーの前後がなめらかに繋がっていて、その滑らかさがそのまま浮遊感になっています。

そこで各キーのタンジェントを切ります。切ると前後を独立して扱えるようになるので、 着地の瞬間だけ鋭い折れ線にできます。地面に当たった感じが出ます。

アニメーションエディタは中ドラッグでズームとトラックができます。跳ねている範囲に寄って作業します。

切った後は、必要に応じて片側だけ引き出して形を作れます。 カーブの形をこちらで決められる状態になった、というのがここでの成果です。

4. テンポを上げる

もう少し速くしたい場合は、Shift でキーを全部選んで、 中ドラッグで時間方向に縮めます。動画では終わりが 30 くらいになるまで詰めています。

これで跳ねる動きがアニメーションの前半に集まって、テンポが上がります。 1つずつキーを動かさずに全体の速さを変えられるので、詰めの段階で使いやすい操作だと思います。

5. モーションパスで軌跡を直接いじる

設定の Motion Path からバインドすると、ボールの軌跡が画面に出ます。 動画では表示範囲を 100 にしています。

これが便利なのは、軌跡の上の点をそのまま掴んで動かせることです。

  • フレーム1の点を上げれば、最初の落下が高くなります
  • バウンスの点を横にずらせば、跳ねる位置が変わります
  • 「ここのバウンスをもう少し大きく」といった判断を、軌跡を見ながら直接反映できます

数値やカーブではなく絵として軌跡を見て決められるので、 バウンスの練習にはかなり向いている道具だと思います。調整が終わったらアンバインドします。

6. スクワッシュ＆ストレッチを付ける

ここからは root ではなく squash control を触ります。 前回 Set Driven Key で繋いだ青いボックスです。

基本の考え方はこうです。

タイミング形
落下中伸びる（ストレッチ）
着地の直前少し戻して丸めに近づける
着地の瞬間潰れる（スクワッシュ）。落差が大きいほど深く潰します
離れた直後いったん均す
頂点少し伸ばす。最初ほど強くはしません
最後0 にして完全な丸に戻して K

各タイミングで K を押しながら進めていきます。 落差の大小に合わせて潰し量を変えるのが要点で、 2回目・3回目のバウンスは跳ねが小さいので潰しも浅くします。

操作するのはハンドル1つ（上下）だけです。 体積を保つ変形は前回の Set Driven Key に仕込んであるので、 ここでは「どれくらい潰すか」だけを考えれば済みます。リグを作った効果がここで出ます。

付け終わったらアニメーションエディタで並べて見ると、 「大きく潰す → 少し潰す → もっと少し」という流れが確認できます。 強調したければここでさらに触れます。

7. USD として書き出す

アニメーションができたら、レンダリングのために USD で書き出します。 Tab から USD の書き出しノードを置いて、キャラクターの出力を繋ぎます。

設定値
ノード名soccerball_anim
ルートのプリムパス/geo
フレーム範囲Current Frame Range（1〜120）
ファイル名$OS のまま。ノード自身の名前に展開されるので soccerball_anim になります

$OS を使っているので、ノード名を変えればファイル名も付いてきます。 レッスン1で出てきた「パスを直に打たずに変数で書く」がここでも効いています。

Save to Disk で書き出したら、次は Solaris に戻ってこれを読み込みます。

この回のまとめ

  • フレーム範囲はグローバルアニメーションオプションで先に決めます（1〜120）
  • キーを並べる → 後から高さを付ける、という順番で進められます
  • 「浮いて見える」のはカーブのなめらかさが原因です。タンジェントを切ると着地が鋭くなります
  • キーを全選択して中ドラッグで縮めれば、全体のテンポを変えられます
  • モーションパスをバインドすると、軌跡の点を直接掴んでバウンスを調整できます
  • スクワッシュ＆ストレッチは落差に比例させます。跳ねが小さいところは潰しも浅くします
  • 触るハンドルは1つだけです。体積保存は前回リグに仕込んであります
  • 書き出しのファイル名は $OS にしておくと、ノード名と一致し続けます

最後の第8回では Solaris に戻り、1つのネットワークの中に2つのショットを共存させて、 Karma XPU で120フレームを連番レンダリングします。 同じ camera1 をショットごとに編集して使い分ける、というのがポイントになります。
