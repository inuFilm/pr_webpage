APEX に複数キャラを入れる — Scene Add Character を数珠つなぎ

houdini-animation / 2026-08-24

出典: Houdini 22 | How to Set Up Multiple Characters （SideFX 公式「Houdini 22 How-To」の1本 / Houdini 22 / 2:20 / 英語）。 このページは、上記の動画を見ながら自分用にまとめた日本語の学習メモです。SideFX 公式の翻訳ではありません。

この回で扱うこと

2分20秒しかない回なので、要点も1つです。 APEX Scene Add Character を数珠つなぎにするだけで、 1つの APEX シーンにキャラクターを何人でも入れられます。

  • 第1入力に APEX シーン、第2入力にキャラクター
  • これを繰り返すとシーンにキャラが積み上がります
  • 唯一の罠は出力を APEX Character にし忘れること

手順

  1. geo ノードを置いて、中に Electra（Houdini 付属のテストキャラ）を入れます
  2. 出力を APEX Character にします。これをやらないと APEX シーンに追加できません
  3. APEX Scene Add Character を配置します。 キャラは第2入力、第1入力が APEX シーンです。名前を Electra A にします
  4. Scene Animate を繋げば、もうアニメートできます

2人目を足す

  1. geo ノードをコピー＆ペーストします
  2. 区別しやすいようにシェーダを metallic に変えます（木のエレクトラと金属のエレクトラになります）
  3. 2つ目の APEX Scene Add Character を置き、 1つ目の出力（APEX シーン）を第1入力へ、2人目を第2入力へ繋ぎます。名前は Electra B
  4. Scene Animate を繋げば、2人まとめてアニメートできます
入力繋ぐもの
第1入力APEX シーン（前の Scene Add Character の出力、または空）
第2入力キャラクター（出力を APEX Character にした geo）

つまずくところ

出力を APEX Character にし忘れるのが唯一の罠です。 Solaris の中で APEX キャラをアニメートする回でも、 講師が同じミスをして言い直しています。 読み込まれないときは、まずここを確認するのが早いと思います。

この回のまとめ

  • APEX Scene Add Character は第1入力がシーン、第2入力がキャラです
  • 数珠つなぎにすればキャラが積み上がります。特別な設定は要りません
  • geo の出力を APEX Character にしておくことだけ忘れないようにします

同じ Scene Add Character を Solaris の中で使う例が APEX Animate in LOPs にあります。 あちらはライトやセットが入った本番シーンを見ながら同じことをやる話なので、 この回を読んだら続けて見ると理解が繋がると思います。
