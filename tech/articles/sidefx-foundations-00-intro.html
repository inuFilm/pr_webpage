先に持っておきたい地図 — 4つの階層

Houdini でつまずく原因は、機能を知らないことよりも自分がいまどの階層にいるか分からなくなることのほうが多いように思います。 このコースは4つの世界を行き来するので、手を動かす前にここだけ入れておくと迷子になりにくいです。

階層何をする場所か登場するレッスン
/obj
オブジェクトレベル		 シーンに置かれた「もの」の単位。パラメータはそのオブジェクト全体の移動・回転とレンダー設定です。今回は box_object1 として生まれて、後で soccerball_geo にリネームされます 1〜3
SOP
ジオメトリレベル		 オブジェクトの中に入った先。形を作るノードネットワークがここにあります 1〜3、4の一部
/stage
Solaris（LOP）		 USD で組むルックデブ・レイアウト・ライティング専用の世界。カメラ・ライト・マテリアル・レンダリングは全部ここです 4・5・8
アニメーションステート Enter で入る Pose ツールの世界。リグのコントロールを掴んでキーを打ちます 6・7

SOP は「形を計算する」場所、Solaris は「シーンを組んで絵にする」場所です。 だから SOP で作った形は、そのままでは Solaris に存在しません。レッスン4で Scene Import を使って明示的に持ち込みます。 この一方通行が分かると、コースの構造もそのまま見通せるようになります。

レッスン3までに組み上がるもの

レッスン1〜3のゴールは、SOP の1本のチェーンです。 Houdini のグラフは上から下へ流れます。先に完成形を見ておくと、 途中でノードを差し込む場面で迷いにくいと思います。ノード名は Houdini が自動で付けるものそのままです。

#ノードこの時点の設定回
1platonic1Solid Type: Soccer Ball / Radius 0.51
2attribcreate1patches = @primnum / Class: Primitive2
3subdivide1Depth 2。32 プリミティブが 720 になります2
4sphere1ray1 の第2入力へ / radius 12
5ray1Method: Project Rays / Entity: Primitives2
6foreach_beginここからループ2
7polyextrude1Distance 0.1 / Inset −0.022
8foreach_endPiece Attribute: patches2
9uvquickshade1UV の確認用。最後にオフにします3
10uvflatten1Group: @patches>19（暗いパッチ）3
11uvflatten2Group: @patches<20（明るいパッチ）3
12fuse1押し出したピースを溶接します2
13subdivide2Depth 12
14matchsize1Justify Y: Min / Target Size 1,1,1 / Scale to Fit3
15SOCCERBALL_OUTOutput / Index 03

sphere1 だけが縦一列から外れます。ray1 の第2入力に繋いで、 レイを飛ばす先の「完全な球」を渡すためです。ここがこのネットワークで唯一の分岐になります。

ひとつ見落としやすいのが UV の3つが fuse1 より前にいることです。 レッスン2で fuse1 → subdivide2 まで組んだあと、 レッスン3ではそのあいだではなく上流側にUV のノードを差し込みます。 記事を書くにあたって画面で確かめたところ、fuse1 と subdivide2 は直結していました。

用意しておくもの

  • Houdini 22。この内容は Apprentice でも追えます
  • コース付属のレッスンファイル。tex/ にテクスチャ4枚（soccerball_color / reflect / roughness / normal）と backdrop 用のものが入っています
  • レッスン7では、レッスン6で書き出した ball_rig.bgeo を読み込みます

最初にやることは1つだけです。File > Set Project でプロジェクトディレクトリを指定してから保存します。 これで $HIP が確定するので、レッスン5でテクスチャを $HIP/tex/… と書けるようになります。

変数意味使うところ
$HIPhip ファイルのあるディレクトリレッスン5のテクスチャパス
$OSそのノード自身の名前レッスン7の書き出しパス
$F22桁パディングのフレーム番号レッスン8の連番レンダリング

パスを直に打たずに変数で書くのが Houdini の作法です。 このコースでも自然にそう書かれているので、真似しておくと後で困りません。
