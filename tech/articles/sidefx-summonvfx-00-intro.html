題材キャラクターがポータルから召喚されるリアルタイム VFX を1カット

Houdini でメッシュとテクスチャと布を作り、Unreal に持ち込んで Niagara で組み、 Sequencer で1カットに仕上げるところまで通します。 リアルタイム向けなので、判断の基準がオフラインレンダリングとはっきり違うのが面白いところだと思います。

先に押さえておきたい3つの考え方

このシリーズは6本ばらばらの内容ではなく、同じ発想が繰り返し出てきます。 先にこれだけ知っておくと、各回で何をしているのか見失いにくいです。

1. パックテクスチャ — 1枚に3〜4種類を詰める

テクスチャを用途ごとに1枚ずつ作るのではなく、グレースケールの情報を R / G / B / A に詰め込んで1枚にします。 Copernicus では channeljoin（Channel Join）がその役です。

Unreal 側では Texture Sample から必要なチャンネルだけを取り出して使います。 テクスチャの枚数＝サンプリング回数なので、リアルタイムではこれが素直に効きます。 レッスン2で作るテクスチャは、ほぼ全部この形になっています。

2. UV2 — 1つのメッシュに UV セットを複数持たせる

メッシュを作るときに uvproject（UV Project）の UV Attribute を uv2 にして、 標準の uv とは別に2組目を持たせます。 Unreal 側で「模様用の UV」と「流れ用の UV」を使い分けられるようになります。

3. 頂点カラー — メッシュ自身にグラデーションを持たせる

attribadjustcolor（Attribute Adjust Color）で、Pattern Type を Radial や Line にして 内側から外側へ、あるいは上から下へのグラデーションをメッシュに焼き込みます。 テクスチャを1枚増やさずにフェードが作れるので、これもリアルタイム向けの発想です。

訳語について

ノード名やパラメータ名は Houdini / Unreal の UI 表記に合わせて英語のままにしています （Labs Disc、Stamp Points、Channel Join、Niagara など）。 検索したときに公式ドキュメントや動画と突き合わせやすいほうがよいかなと思ってそうしました。

なお動画の音声だけを追うとノード名を取り違えやすい回があります。 たとえば Copernicus の sopimport（SOP Import）は「sub import」、 dilateerode（Dilate Erode）は「delayed erode」、 worleynoise（Worley Noise）は「whirly noise」のように聞こえます。 このメモでは画面と Houdini 22.0.368 の実機で照合した名前を書いています。
