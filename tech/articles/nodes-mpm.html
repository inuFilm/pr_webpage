この記事で扱うこと

  • MPM が何を解くものなのか（FLIP・Vellum・RBD との住み分け）
  • SOP 8個 + DOP 2個を全部、1ノードずつ
  • 材料の性質がどのパラメータで決まるか

MPM は「粒子とグリッドを行き来する」ソルバ

MPM（Material Point Method / 物質点法）は、材料を粒子で持ちながら、 力の計算だけグリッドで行い、また粒子に戻す、という往復で解きます。 FLIP と似た構造ですが、狙っているものが違います。

ソルバ得意なもの
MPM雪・砂・泥・粘土・肉・パン生地。形が残る／崩れるもの。 固体と流体の中間にあるものが一番の得意分野
FLIP水。形が残らない液体
Vellum布・紐・風船。薄いもの、伸び縮みするもの
RBD剛体。割れるが変形はしないもの

「砂の山を崩す」「雪に足跡が残る」「粘土がひしゃげる」のように、 変形したまま止まるものは MPM の担当です。

並びは Pyro や FLIP と同じ形で、器 → 材料 → 障害物 → 解く → 出口です。

1. 器を決める

MPM Container mpmcontainer

やること解く領域・解像度・開始フレームを決める
使いどころMPM を組むときの起点
入力0〜1
要のパラメータparticlesep — 粒子の間隔。細かさと重さを決める主役（既定 0.025）
gridscale — グリッドを粒子間隔の何倍にするか（既定 2）
size — 領域の大きさ（既定 10.0 10.0 10.0）
startframe — 開始フレーム（既定 1）
friction — 領域の壁の摩擦（既定 1）
sticky — 壁への貼りつき（既定 0）

領域の各面（xneg / xpos …）ごとに、通す・止めるを設定できます。

2. 材料をつくる

MPM の性格はここで決まります。同じソルバでも、ここの設定で雪にも砂にも粘土にもなります。

MPM Source mpmsource

やることメッシュやボリュームから MPM の粒子を作る。材料の性質もここで持たせる
使いどころ崩したい・ひしゃげさせたいものを渡すとき
入力1〜2
要のパラメータdensity — 密度。重さ（既定 400）
e — ヤング率。硬さ。大きいほど硬い（既定 1.4）
nu — ポアソン比。潰したときの横への膨らみ方（既定 0.2）
compressionhardening — 潰れたときに硬くなる度合い。雪らしさはここ（既定 10）
emission — 時間とともに湧かせるか（既定 1）
enablepinconstraint — 一部を固定して動かなくする（既定 False）
注意硬さは e（ヤング率）です。名前が1文字なので見落としやすいのですが、砂と粘土と雪の違いはほぼここと compressionhardening の組み合わせで出ます。

公式リファレンス（英語）

3. ぶつかるものを渡す

MPM Collider mpmcollider

やることVDB のコリジョンを定義する。跳ね返す／消す
使いどころ地面・器・キャラクターに当てるとき
入力1〜2
要のパラメータtype — コリジョンの種類（既定 0）
response — 当たったときの応答（跳ねる／止まる／消す）（既定 0）
friction — 摩擦。砂が斜面で止まるかどうかはここ（既定 1）
sticky — 貼りつき（既定 0）
computevelocity — 動くコリジョンの速度を材料に伝える（既定 True）

公式リファレンス（英語）

4. 解く

MPM Solver (SOP) mpmsolver

やることMPM を解く
使いどころ器・材料・コリジョンを渡した先に置く本体
入力1〜3
要のパラメータcflcondition — サブステップの自動決定。小さくすると安定するが遅くなる（既定 1）
airdrag — 空気抵抗（既定 0）
cacheenabled — メモリキャッシュ（既定 True）
deterministic — 毎回同じ結果になるようにする（既定 True）
autoresim — 上流が変わったら解き直す（既定 True）

重い処理なので、まず particlesep を粗くして動きだけ見ます。

5. 出口 — 絵にする

MPM の出力は粒子です。そのままではレンダーできないので、面にするか、元のモデルに動きを移します。

MPM Surface mpmsurface

やること粒子から面を作る
使いどころ砂・泥・雪など、元の形が残らないものの出口
入力0〜4
要のパラメータkernelradius — 1粒が影響する半径。大きいと膜っぽく、小さいと粒っぽくなる（既定 2）
enablesmooth — 表面をならす（既定 False）
iterations — ならす回数（既定 1）
adaptivity — 平らなところの面を減らす（既定 0.005）
fillinterior — 内部を埋める（既定 False）

公式リファレンス（英語）

MPM Deform Pieces mpmdeformpieces

やることMPM の動きを、レンダー用の元モデルに移す
使いどころ形が保たれるもの（粘土のかたまり、肉）の出口。面を作り直すより元のモデルのほうがきれいなとき
入力1〜2
要のパラメータkernelradius — 粒子からの影響半径（既定 10）
enableattribtransfer — UV などの属性も一緒に運ぶ（既定 False）
closegaps — 隙間を閉じる

mpmsurface と使い分けます。崩れて原形をとどめないなら mpmsurface、ひしゃげるだけで元の形が分かるなら mpmdeformpieces のほうがきれいです。

公式リファレンス（英語）

MPM Post Fracture mpmpostfracture

やることMPM の最終状態を使って、レンダー用ジオメトリを割る
使いどころちぎれた・割れた結果を、元モデルの割れとして表現したいとき
入力2
要のパラメータdofracture — 割りを有効にする（既定 True）
elementsize — 割れの細かさ（既定 1）
amplitude — 割れ目の乱れ（既定 1）

公式リファレンス（英語）

MPM Debris Source mpmdebrissource

やることMPM から、二次シミュレーション用の点を取り出す
使いどころ砂埃を Pyro で足す、破片をパーティクルで飛ばす
入力1〜2
要のパラメータminspeed — 取り出す最低速度（既定 0.5）
ratiotokeep — 取り出す割合（既定 1）
pscalemult — 取り出す点の大きさ倍率（既定 0.35）

「速く動いているところだけ」「引き伸ばされているところだけ」を条件にして取り出せます。砂煙を足すときの入口になります。

公式リファレンス（英語）

材料の作り分け

MPM の勘所は mpmsource にほぼ集まっています。 どれも e（硬さ）と、潰れたときの振る舞いの組み合わせです。

作りたいもの効くところ
砂硬さは低め。mpmcollider の friction を上げると 斜面で止まるようになる
雪compressionhardening を効かせる。踏んだところが固まる
粘土・パン生地硬さ低め・硬化なし。出口は mpmdeformpieces
泥硬さをかなり低く。ほとんど液体寄り
症状まず見るところ
爆発したように飛び散るcflcondition を小さく。硬さ e が高すぎないか
斜面で止まらず流れ続けるmpmcollider の friction
面がぬるっとしすぎるmpmsurface の kernelradius を小さく
とにかく重いparticlesep。まず粗く
