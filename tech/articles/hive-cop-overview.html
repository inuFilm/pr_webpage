誰の講演か

普段はモバイルゲームの仕事をしている人です。 実際に手を動かしている人の視点で、H22 の新しいマテリアルレイヤー系ノードを 次々に見せていく33分になっています。

機能紹介というより「これで何が作れるか」を見せる構成なので、 Copernicus で何ができるのか全体像を掴むのに向いた講演だと思います。

1. マテリアル層の新ノード群

錆びた表面や湿りを作るためのノードが揃っています。

ノード役
Grungeレイヤー間の鋭い遷移を扱います
Sheets同様に遷移を扱います
Drips / Small Spots / Streaks / Wipe Trails目的別に用意されたもの

「汚しを作る」というひとつの目的に対して、 現象ごとに別のノードが用意されているのが H22 のマテリアル系の特徴です。 ノイズを組み合わせて自分で作る、という段階から一段上がっています。

Sheets の閾値でグローを作る

07:09 からは「他より深い部分をシミュレートする」話になり、 Sheets の閾値でグローを作っています。 Leaky Streaks と Drips も出てきます。

汚しのノードを発光に転用するという使い方で、 「濡れて深く見えるところが光る」という現象を作っています。

2. Tile Pattern

10:48 からの Tile Pattern ノードについて、こう言っています。

既に使ったことがあれば、インターフェースの上半分は見覚えがあるはず。

つまり既存のタイル系ノードの延長にあるものです。 新しく覚えるのは下半分だけ、ということになります。

すべてが同じ元から派生する

14:22 からが面白い部分です。絡み合う葉の間の「枝」を作るのに、 shape と別の tile pattern を使い、Max ブレンドで合成します。

そして重要なのがこの一言です。

すべてが同じ元から派生しているので、ぴったり合う。

葉と枝を別々に作ってから位置を合わせるのではなく、 同じパターンから両方を導くので、そもそもずれません。 手続き的に作ることの本質的な利点が、この一例に出ていると思います。

3. Mask Combine

21:33 で Mask Combine ノードを実演しています。

講演時点では最終的な名称を検討中だったそうですが、おそらくこの名前で確定しています。

4. curvature マスクから肌を作る

25:04 からは curvature マスクから肌の色を作る話です。 特に翼のような薄い部分に効くとのことです。

そして骨っぽい部分は別のアプローチで作っています。

「1つのマスクで全部やる」のではなく、 部位の性質ごとに違うマスクの作り方をするという判断です。 薄くて張った部分と、骨が浮いている部分では、curvature の出方がそもそも違います。

5. Q&A

質問答え
白黒の値からメッシュを再生成できるか ある程度は可能。ただしニット（編み目）はかなり難しい
adjacency ノードについて Jakub さんの講演が詳しいと案内されます

「ニットは難しい」という具体的な限界が出てくるのが実践者らしくて良いなと思いました。 高さ情報からジオメトリを起こすのは、糸が交差しているような構造だと成立しません。

この講演から持ち帰るもの

  • H22 のマテリアル層は現象ごとにノードが用意されています（Grunge / Sheets / Drips / Small Spots / Streaks / Wipe Trails）
  • Grunge と Sheets はレイヤー間の鋭い遷移を扱うためのものです
  • Sheets の閾値をグローに転用できます。「深く濡れたところが光る」を作れます
  • Tile Pattern は既存のタイル系ノードの延長で、上半分は見覚えのあるインターフェースです
  • 葉と枝を同じパターンから導けば、位置合わせが不要になります。手続き的に作る利点そのものです
  • 肌は curvature マスクから。ただし部位の性質ごとに別のアプローチを取ります
  • 白黒からメッシュ生成はある程度可能。ニットは難しいという具体的な限界
