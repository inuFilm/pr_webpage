ライトとカメラ — 型の対応と、数字が変わる話

houdini-solaris / 2026-08-19

出典: SideFX 公式ドキュメント Light / Dome Light / Camera / Light Mixer。 このページは上記を日本語で要約・再構成した学習メモです。 ノードのメニューと USD の型の対応、パラメータの値は Houdini 22.0.368 の実機で確認しています。

この記事で扱うこと

  • ライトのノードが、USD 側でどの型になるのか（実測しました）
  • 明るさの決まり方 — Intensity と Exposure の関係
  • カメラの3つの約束と、パラメータの数字が USD に入る数字と違うという話
  • light / domelight / lightmixer / lightlinker / camera のノード解説

ライトのノードは3種類に分かれる

LOP のライトは、見た目より整理されています。3つのグループに分けて考えると迷いません。

グループノード役割
形のあるライト light 1ノードでメニュー切り替え。長方形・球・円盤・円柱・点・平行光
環境光 domelight / karmaskydomelight 周囲ぜんぶから当てる。HDRI を貼るのはこれ
特殊 distantlight / geometrylight / portallight 太陽光、ジオメトリ自体を光らせる、窓からの光を効率化する

メニューと USD の型の対応（実測）

light LOP のメニューを切り替えて、実際にどの型のプリムができるか確かめました。

ノードのメニューできる USD の型
UsdLuxRectLightRectLight
UsdLuxDiskLightDiskLight
UsdLuxSphereLightSphereLight
UsdLuxCylinderLightCylinderLight
UsdLuxDistantLightDistantLight
pointSphereLight ＋ treatAsPoint = true
Dome Light LOPDomeLight_1

面白いのが point です。専用の型があるわけではなく、 球ライトに「点として扱う」という旗を立てただけでした。 実機で treatAsPoint を読んだら true になっていました。

これは第3回のプリムパターンにも効いてきます。点光源を選びたいと思って %type:PointLight と書いても0個です。%type:SphereLight が正解になります。

明るさの決まり方

ライトのパラメータは多いのですが、明るさに効くのは実質この4つです。

パラメータUSD の属性効き方
Intensityinputs:intensityそのまま倍率。既定 1
Exposureinputs:exposure2のべき乗で効きます。既定 0
Colorinputs:color色。既定 (1, 1, 1)
Normalizeinputs:normalize大きさで割るかどうか。既定オフ

Intensity と Exposure が両方あるのは、掛け算の道具が2つあるということです。 最終的な明るさは、ざっくり intensity × 2^exposure になります。

Exposure を 1 増やすと2倍、2 増やすと4倍。カメラの露出と同じ感覚ですね。 細かく詰めるときは Intensity、大きく振るときは Exposure、という使い分けがしやすいと思います。

Normalize は引っかかりやすいところです。オフのままだと、 ライトを大きくするとその分だけ明るくなります（面積が増えるので当然といえば当然です）。 オンにすると、大きさを変えても明るさが変わりません。 「柔らかくしたいだけなのに明るくなってしまう」ときは、ここをオンにします。

色温度で指定したい場合は Enable Color Temperature をオンにします。 既定はオフで、そのときは Color がそのまま使われます。

カメラの3つの約束

USD のカメラには、覚えておかないと混乱する決まりが3つあります。

約束1 — 常に Y が上

USD のカメラは、ステージの up axis が何であっても Y up です。 Houdini のシーンを Z up で作っていても、カメラだけは Y up。ここは例外です。

約束2 — 常に −Z を向く

カメラが見ているのは常に −Z 方向です。 カメラの向きを式で作るときは、これを前提にします。

約束3 — パラメータの数字と USD の数字は違う

これが実機でいちばん驚いたところです。

見る場所Focal Length の値
Camera LOP のパラメータ50
USD の focalLength 属性0.5

パラメータはミリメートルで入力しますが、USD は 「ワールド単位の 1/10」で保存するという決まりになっています。 ステージの metersPerUnit が 1 なら、50mm = 0.05m = 0.5、というわけですね。

Scene Graph Details で数字を見て「あれ？」となっても、壊れてはいません。 Aperture 系のパラメータも同じ扱いです。

ノードごとの解説

Light light

やること形のあるライトを1つ作る（または既存を編集する）
入力0〜1
要のパラメータlighttype、primpath（既定 /lights/$OS）、Intensity、Exposure
ビューポート操作Enter でハンドル。Shift+D で「面に対して垂直に置く」、Shift+S で「ここにハイライトが出るように置く」

ビューポートでの置き方が便利なので、少し書いておきます。

キーモード
Shift + Dクリックした面に対して垂直にライトを置く
Shift + Sクリックした場所にハイライトが出るように置く
Shift + F影の落ち方を見ながら置く
Shift + TLook At を有効にして、狙いを付ける
Ctrl + Shift ドラッグ明るさを変える

Shift+S は、ハイライトの位置からライトの位置を逆算してくれるものです。 「そこが光ってほしい」から入れるので、考え方として素直だと思います。

Dome Light domelight

やること周囲ぜんぶから当てる環境光を作る
要のパラメータTexture（HDRI のパス）、Format、Pole Axis、Intensity / Exposure
Format既定は Automatic。緯度経度マップかキューブマップかを推測します
Pole Axisドームの上をどこに向けるか。既定は Scene（ステージの up axis に合わせる）
Portals窓がある室内で、サンプリングを効率化するための誘導口

第0回の最小構成でこれを1つ置いただけで絵が出たのは、 テクスチャが無くても白い環境光として機能するからです。

Houdini 22 の Dome Light は DomeLight_1 という新しいスキーマでプリムを作ります。 古い DomeLight ではないので、パターンで拾うときは注意です（第3回参照）。

Light Mixer lightmixer

やることシーン中のライトを1枚のパネルにまとめて、スライダーで調整する
向いている場面ライトが増えてきて、ノードを行き来するのがつらくなったとき

照明の調整は「全体のバランス」を見る作業なので、 ノードを1つずつ開くより、こういうパネルのほうが速いです。

Light Linker lightlinker

やること「このライトは、このオブジェクトだけを照らす」という関係を作る
向いている場面物理的には正しくないけれど、絵として必要な調整

指定にはプリムパターンが使えます。第3回のコレクションと組み合わせると管理しやすくなります。

Camera camera

やることUSD のカメラを作る
要のパラメータprimpath（既定 /cameras/$OS）、Projection、Focal Length（既定 50）、 Horizontal Aperture、Clipping Range
被写界深度F-Stop と Focus Distance。Shift+F で焦点面を可視化できます
Look At他のプリムを狙わせる。Constraints セクション

Aperture の指定方法が2通りある点だけ補足しておきます。 Control Aperture を Set Horizontal Aperture and Aspect Ratio にすると、 横幅とアスペクト比で指定できます。この形にしておくと、 Render Settings 側が解像度を自動で合わせられるようになります。

詰まりやすいポイント

  • ライトを大きくしたら明るくなりすぎた → Normalize をオンにします。
  • %type:PointLight で選べない → 点光源は SphereLight です。 treatAsPoint が立っているだけの球ライトでした。
  • Scene Graph Details の数字がパラメータと違う → 仕様です。 mm と「ワールド単位の 1/10」の違いで、だいたい 1/100 になります。
  • Z up のシーンなのにカメラが変な向き → USD のカメラは常に Y up・−Z 向きです。
  • ドームライトの回転が思ったのと違う → Pole Axis を確認します。既定は Scene です。
