Morse Atelier — モールス信号の練習室

学習英字・数字ホバーパドルオフライン可

T → M → O、E → I → S → H、E → A → W → J。分岐図の道をたどって、英数字のモールス符号を覚える練習アプリです。

  • 黒と金の分岐図に入力中の経路を表示。文字を選んで符号と音を確認
  • 縦長のダブルパドルにマウスを重ねて打鍵。1打 / 連打切り替え、F / J キーとタッチにも対応
  • 自由入力・文字練習・文章練習。英数字の文章を自分で指定して正誤判定とお手本再生
  • 速度、文字の確定待ち、音量、ヒントと文字表示を調整可能。外部送信なし

漢字サモナーズ（漢字召喚RPG）

試験公開タブレット推奨小学1〜2年生書き順オフライン可

漢字を正しい書き順で書くこと自体がバトル操作になる、漢字学習ゲームです。一画ごとに魔力がたまり、漢字が完成すると意味に対応した魔法・召喚が発動します。

  • 小学1年生・2年生の配当漢字 240 字をすべて収録。1年生の漢字は最初から使える基本魔法、2年生の漢字は冒険で手に入れる新しい魔法
  • 判定するのは書き順（始点・方向・終点）。字の形は多少くずれても OK。ミスすると敵が攻撃、ノーミスならクリティカル
  • むずかしさ 3 段階（ふつう / 上級: ガイドなし / 超上級: 漢字も隠れて読みだけ）
  • 苦手な画だけヒントが強くなり、苦手な漢字はバトルの中で自然に再出題
  • マウス / 指 / ペンに対応。横画面推奨。進行と習熟度は端末内（localStorage）に保存
  • 書き順データは KanjiVG（CC BY-SA 3.0）を使用

CGの数学を、数式なしで。

学習文系向けHoudini / VEX触れる図オフライン可

CG の数学を、数学記号を一切使わず「プログラムの書き方」だけで学ぶ教材です。各章に触って動かせる図があり、計算できなくても「何をしているか」が分かることを目標にしています。

  • 前半: ベクトル・内積・外積・sin/cos・行列・投影・補間・四元数・重心座標。すべて dot(a, b) のようなコード表記
  • 後半: ノイズ・タイリング・距離関数・極座標・フーリエ変換・L-system・フラクタル・黄金角・ボロノイ・反応拡散・セルオートマトン・物理・ベジェなど、Houdini でよく使う「模様と動き」の数学
  • 各章に「Houdini でやるなら」の VEX / SOP 対応、1問の理解チェック。進捗は端末内（localStorage）に保存
  • 最後に LLM（言語モデル）の中身が同じ数学でできていることを見る章と、数学記号 → コード / VEX の対応表
  • Part 6: Pyro（速度場・圧力投影）/ FLIP / RBD / Vellum / MPM の仕組みを、ブラウザ上で動く 2D シミュレーションで解説

追加：サンプリング・sRGBと線形補間・曲線の等速移動の比較実験。全40章。VFX版の対応章へ行き来できます。

ゲームVFXの原則を、動く図で。

学習リアルタイムVFXエンジン非依存GLSL触れる図オフライン可

ゲームのエフェクト（リアルタイム VFX）を、エンジンの手順ではなく「形・動き・時間」の原則として学ぶ教材です。「CGの数学を、数式なしで。」の続きとして、各章で使う数学をその章にリンクしています。

  • Part 1: UV・流す＋抜く・歪み・ディゾルブ・極座標・ランプ・ブレンド・フレネルとソフトパーティクル・頂点オフセット・ループ・全部つなぐサンドボックス・光を受ける板。図の下のシェーダーコード（GLSL）は、その図で実際に動いているコードそのもの
  • Part 2: 発生と寿命・寿命カーブ・速度と力・ビルボードとリボン・リボンの UV・フリップブック・オーバードロー。パーティクルを「たくさん飛ばす」側の原則
  • Part 3: タイミング（溜め・衝撃・余韻）・可読性・色の階層・要素の役割。ヒットエフェクトを時間で前後に動かしながら組み立てる
  • Part 4: レシピ。炎・煙・雷・斬撃・回復・衝撃波を、前の章の部品だけで組む（部品と設定の表付き）
  • Part 5: 数学アプリの章、GLSL / HLSL / VEX の関数名、ノード式エディタで探す言葉への対応表
  • 画像素材は使わず、炎もフリップブックも全部ブラウザ内で計算。各章に理解チェック 1 問。進捗は端末内（localStorage）に保存

追加：ちらつき・色の合成・リボンの間隔を数学から理解する比較実験。全34章。
