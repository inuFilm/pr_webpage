ツールまとめ

ツール / 2026-08-29

ブラウザでそのまま使える自作ツールをここにまとめていきます。 インストール不要で、読み込んだモデルや作業データはすべて端末内(ブラウザのローカルストレージ)に 保存され、外部サーバーには送信されません。

VRM Pose Ref

iPad対応VRMポーズ資料オフライン可

VRM モデルを読み込んでポーズを付けられる、作画資料用のポージングツールです。 Procreate などと並べて、自分のキャラクターをデッサン人形代わりに使う用途を想定しています。

  • IK 付きの関節ドラッグ、腰を下げるだけでしゃがめる接地固定、手首・足首の捻りコントローラー
  • 立ち・座りポーズ、グー / チョキ / パーなどの手のプリセット、表情・目線の調整
  • glTF / GLB の小物(家具など)の配置、複数キャラクター対応
  • アスペクト比と解像度を指定した PNG 書き出し(透過背景も可)
  • ポーズ・カメラ・シーン構成の保存と .json での受け渡し
起動する

iPad では Safari で開いて「共有 → ホーム画面に追加」すると、全画面表示になりオフラインでも起動できます。 VRM モデルはアップロードされず、端末内でのみ処理されます。
