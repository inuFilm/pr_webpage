VEX は「1要素につき1回」走る

VEX のコードは、点なら点ごと、プリムならプリムごとに独立して1回ずつ走ります。 for ループを書かなくていいのはそのためです。

何を単位にするかは wrangle ノードの Run Over（内部名 class）で決めます。 ここを間違えると「動いているのに何も起きない」になります。

Run Overclass の値1回ぶんの単位
Detail (only once)0ジオメトリ全体で1回だけ
Primitives1プリムごと
Points2点ごと（既定）
Vertices3頂点ごと
Numbers4指定した回数だけ

Vertices は 3 です。 「Detail / Prim / Point」の並びから 2 と思いこみやすいのですが、 スクリプトから class を設定するときにここを外すと静かに別の単位で走ります（実測で踏みました）。

使える変数

変数中身
@ptnum / @primnum / @vtxnum今の要素の番号
@numpt / @numprim / @numvtx総数
@P位置（vector）
@N / @v / @Cd法線 / 速度 / 色
@pscale / @id / @age大きさ / 識別子 / 年齢
@Time / @Frame / @TimeInc時間 / フレーム / 1フレームの秒数
@elemnum / @numelem単位によらない番号と総数
@ix / @iy / @izボリュームのボクセル添字（Volume Wrangle）

@ は型を明示する

既存のアトリビュートを読むだけなら @name でよいのですが、 新しく作るときは型を書かないと float になります。

v@up      = {0, 1, 0};   // vector（3成分）
f@mass    = 1.5;         // float
i@piece   = 3;           // int
s@name    = "rock";      // string
p@orient  = {0,0,0,1};   // vector4（クォータニオン）
4@xform   = ident();     // matrix（4x4）
3@rot     = ident();     // matrix3（3x3）
2@uv      = {0.5, 0.5};  // vector2
f[]@radii = {1, 2, 3};   // 配列

v@up と書くべきところを @up と書くと、 float の up が作られて、後段が読めずに 0 になります。エラーは出ません。

1. VEX を書く場所（wrangle 系ノード）

どれも「VEX スニペットを走らせる」だけのノードですが、走る文脈が違います。

Attribute Wrangle attribwrangle

やることジオメトリのアトリビュートを VEX で書き換える。SOP の主力
使いどころ点・プリム・頂点・detail のどれでも。迷ったらこれ
入力0〜4
要のパラメータclass — Run Over。Vertices は 3（既定 2）
snippet — VEX のコード本体
group — 対象を絞る
vex_updatenmls — 位置を動かしたら法線も作り直す（既定 False）
注意入力は 0 番だけが出力されます。入力1・2 に別のジオメトリを差して @inputnum で分けたつもりでも、入力1側はシーンに出てきません（実測で踏みました）。種類ごとに wrangle を分けて merge するのが正解です。

2. パラメータを引く

ノードのパラメータや、ほかのノードの値を VEX から読みます。CTRL に値を集める作り方はこれで成り立っています。

関数説明
chf("name")float を引く。そのノードに無い名前なら、Create Spare Parameters で作れる
chi("name")int を引く
chv("name")vector を引く
chs("name")string を引く
chp("name")vector4 を引く
ch("../CTRL/size")パスで他ノードのパラメータを引く。相対パスが書ける
chramp("ramp", pos)ランプパラメータを位置 0〜1 で評価する

chf("radius") と書いてからノードの Create Spare Parameters を押すと、その名前のパラメータが自動で生えます。CTRL に集める作りはこの往復で作ります。

// CTRL の値を引いて使う。ノードには値を直に書かない
float r    = chf("../CTRL/radius");
int   seed = chi("../CTRL/seed");
vector up  = chv("../CTRL/up");

@P += up * r * rand(@ptnum + seed);

3. ジオメトリを読む

別の入力や別のノードから値を持ってくるのがここです。第1引数の 0 1 2 は入力の番号、文字列ならノードのパスです。

アトリビュートを読む

関数説明
point(0, "P", i)入力0の点 i の P を読む
prim(0, "name", i)プリム i の属性を読む
vertex(0, "uv", i)頂点 i の属性を読む
detail(0, "count", 0)detail 属性を読む
pointattrib(0, "Cd", i, ok)読めたかどうかも受け取る（ok に 0/1 が入る）
primattrib(0, "Cd", i, ok)同上のプリム版
haspointattrib(0, "Cd")その属性があるか
hasprimattrib(0, "name")プリム版
hasdetailattrib(0, "count")detail 版
npoints(0)点の数
nprimitives(0)プリムの数
primpoints(0, i)プリム i を構成する点番号の配列
pointprims(0, i)点 i が属するプリム番号の配列
primuv(0, "P", prim, uv)プリム上の任意の位置で属性を補間して読む

属性が無いときは黙って 0 が返ります。「値が全部 0 になる」ときは、まず haspointattrib() で存在を確かめてください。

書く

関数説明
setpointattrib(0, "Cd", i, v)点 i に書く。detail 実行のときによく使う
setprimattrib(0, "name", i, s)プリムに書く
setdetailattrib(0, "count", n)detail に書く
setattrib(0, "point", "Cd", i, -1, v)汎用。書き込み方（set/add/max…）も選べる

書き込み先の 0 は「自分の出力」です。入力を書き換えているわけではありません。

// detail で1回だけ走らせて、全部の点に書く
int n = npoints(0);
for (int i = 0; i < n; i++) {
    vector p = point(0, "P", i);
    setpointattrib(0, "Cd", i, set(p.y, 0, 1 - p.y));
}

作る・消す

関数説明
addpoint(0, pos)点を足す。戻り値が新しい点番号
addprim(0, "polyline", a, b)プリムを足す
addvertex(0, prim, pt)プリムに頂点を足す
removepoint(0, i)点を消す
removeprim(0, i, 1)プリムを消す（第3引数が1なら点も一緒に）
// 各点から法線方向に線を1本ずつ生やす
int a = addpoint(0, @P);
int b = addpoint(0, @P + @N * chf("len"));
int l = addprim(0, "polyline", a, b);

4. 数学 — 値をならす・範囲を移す

いちばん出番が多いのはここです。ノイズや距離を「使える範囲」に押し込む道具が揃っています。

関数説明
fit(x, omin, omax, nmin, nmax)範囲を移し替える。範囲外はクランプされる
fit01(x, nmin, nmax)0〜1 を新しい範囲へ。rand() の後にほぼ必ず使う
fit11(x, nmin, nmax)-1〜1 を新しい範囲へ。ノイズの後はこちら
efit(x, omin, omax, nmin, nmax)fit のクランプなし版
clamp(x, lo, hi)範囲で止める
lerp(a, b, t)線形補間
smooth(lo, hi, x)0→1 のなめらかな立ち上がり（S字）。smoothstep という名前は無い
abs(x)絶対値
sign(x)符号（-1 / 0 / 1）
min(a, b)小さいほう
max(a, b)大きいほう
floor(x)切り捨て
ceil(x)切り上げ
rint(x)四捨五入。round という関数は無い
frac(x)小数部だけ
pow(x, n)べき乗
sqrt(x)平方根
exp(x)指数
log(x)自然対数
sin(x)サイン。引数はラジアン
cos(x)コサイン
atan2(y, x)2引数のアークタンジェント。角度を出すならこれ
radians(deg)度 → ラジアン
degrees(rad)ラジアン → 度
sum(arr)配列の合計
avg(arr)配列の平均

round は無いので rint() を使います。fmod も無いので剰余は % 演算子（float でも使えます）。

// 高さでグラデーションを作る典型
float h = fit(@P.y, 0, 2, 0, 1);      // 0〜2m を 0〜1 に
h = smooth(0.2, 0.8, h);              // 端をなめらかに
@Cd = lerp({0.2,0.1,0.05}, {0.6,0.9,0.4}, h);

// 角度で分ける
float ang = degrees(atan2(@P.z, @P.x));   // -180〜180
i@side = ang > 0 ? 1 : 0;

5. 乱数とノイズ

同じ入力なら必ず同じ結果が返ります（疑似乱数）。フレームが進んでもチラつかないのはこのためです。

乱数

関数説明
rand(seed)0〜1。seed には @ptnum や @id を入れる
nrandom("twister")呼ぶたびに違う値。順序に依存するので基本は使わない
random(pos)位置を種にした乱数

種を変えるときは足し算ではなく別の数を混ぜます。rand(@ptnum + 1) は隣の点と同じ値になるので、rand(@ptnum + seed * 7919) のように素数を掛けるのが定石です。

int   sd = chi("seed");
float f  = fit01(rand(@ptnum + sd * 7919), 0.6, 1.6);   // 0.6〜1.6 倍
vector r = set(rand(@ptnum), rand(@ptnum + 101), rand(@ptnum + 337));

ノイズ

関数説明
noise(pos)0〜1 のパーリンノイズ
onoise(pos)-1〜1 の原点対称ノイズ。中心が 0 なので足し込みに向く
snoise(pos)スパースコンボリューションノイズ
vnoise(pos, period)周期のあるノイズ（タイリングする）
anoise(pos)エイリアスの少ないノイズ
pnoise(pos, period)周期指定のパーリンノイズ
curlnoise(pos)発散のないノイズ。渦を作るのに使う
flownoise(pos, t)時間で流れるノイズ

turb という関数はありません。乱流（fBm）はオクターブを自分で重ねて作ります（下のサンプルの最後）。ノイズは引数の型で結果が変わります。noise(vector) と noise(vector4) は別の関数で、4番目の成分を時間にすると「動くノイズ」になります。

// 表面をノイズで押し出す。振幅と周波数は必ず分けて持つ
float amp  = chf("amp");
float freq = chf("freq");
float n = onoise(@P * freq);       // -1〜1
@P += @N * n * amp;

// 時間で動くノイズ（4成分目に時間を入れる）
float n2 = onoise(set(@P.x, @P.y, @P.z, @Time * 0.5) * freq);

// 渦を巻く速度場
@v = curlnoise(@P * freq) * amp;

// fBm（乱流）は自分で重ねる。周波数を2倍、振幅を半分にしながら足していく
float n3 = 0, w = 1, f = freq;
for (int i = 0; i < 5; i++) {
    n3 += onoise(@P * f) * w;
    f *= 2.0;
    w *= 0.5;
}

6. ベクトル

関数説明
length(v)長さ
length2(v)長さの2乗。比較だけなら sqrt を省けて速い
distance(a, b)2点間の距離
distance2(a, b)距離の2乗

cross(a, b)外積。2つに垂直なベクトル

set(vector, float) は vector2 になります。vector4 を式の途中で作ろうとして 4 引数の set() を書くと「どの型か決まらない」と怒られるので、いったん変数に受けてください（実測）。

// 法線と上方向から接線の枠（TBN）を作る
vector up = {0, 1, 0};
vector t  = normalize(cross(up, @N));    // 接線
vector b  = cross(@N, t);                // 従法線

// 上を向いている面だけ色を付ける
float d = dot(normalize(@N), up);        // 1 で真上、0 で横、-1 で真下
@Cd = d > 0.7 ? {1,1,1} : {0.2,0.2,0.2};

// 距離の比較は length2 で足りる（sqrt を省ける）
if (length2(@P - target) < r * r) { ... }

7. 行列と回転 — ここだけサンプル多め

Houdini の行列は「行ベクトル × 行列」です。v * m と書きます（m * v ではありません）。ここを逆にすると結果が転置されます。

作る・分解する

関数説明
ident()単位行列。行列は必ずこれで初期化してから積む
maketransform(t, r, s)移動・回転・スケールから行列を作る
instance(pos, dir, scale, up, rot)点に置くためのインスタンス行列を作る
cracktransform(0, 0, c, pivot, m)行列から移動(c=0)/回転(c=1)/スケール(c=2)を取り出す
invert(m)逆行列
transpose(m)転置
determinant(m)行列式。負なら裏返っている
polardecomp(m)回転成分とスケール成分に分ける

回す

関数説明
rotate(m, angle, axis)行列に回転を積む（引数の m が書き換わる）
prerotate(m, angle, axis)回転を前から積む
scale(m, s)スケールを積む
translate(m, t)移動を積む
dihedral(a, b)ベクトル a を b に向ける回転を作る。向き合わせの定番
lookat(from, to, up)from から to を見る回転行列
qrotate(q, v)クォータニオンでベクトルを回す
quaternion(angle, axis)軸と角度からクォータニオンを作る

qmultiply(a, b)クォータニオンの合成

quaterniontoeuler(q, order)クォータニオンからオイラー角

行列の行を取り出すのに m[0] は書けません。set(1,0,0) * m のように単位ベクトルを掛けて取り出します（実測）。

サンプル1 — 点を軸まわりに回す

関数説明
rotate(m, angle, axis)上と同じ関数。ここでは実際の使い方
// Y 軸まわりに、中心からの距離に応じてねじる
float amount = chf("twist");        // 度
vector pivot = {0, 0, 0};

matrix3 m = ident();
rotate(m, radians(amount) * @P.y, {0, 1, 0});

@P = (@P - pivot) * m + pivot;      // **行ベクトル × 行列**
@N = @N * m;                        // 法線も同じ行列で回す（移動は掛からない）

サンプル2 — 向きを合わせる（dihedral）

関数説明
dihedral(a, b)a を b に向ける最短回転
// 上向きに作ったカードを、点の法線の向きに寝かせる
matrix3 m = dihedral({0, 1, 0}, normalize(@N));
@P = @P * m;

// copytopoints に渡すときは orient を作っておくと確実
p@orient = quaternion(dihedral({0, 0, 1}, normalize(@v)));

サンプル3 — 行列から成分を取り出す

関数説明
cracktransform(0, 0, c, pivot, m)0=移動 / 1=回転 / 2=スケール
// パックプリムの変換から、位置・回転・スケールを取り出す
matrix m = primintrinsic(0, "transform", @primnum);
vector t = cracktransform(0, 0, 0, {0,0,0}, m);   // 移動
vector r = cracktransform(0, 0, 1, {0,0,0}, m);   // 回転（度）
vector s = cracktransform(0, 0, 2, {0,0,0}, m);   // スケール

// 行を取り出す。**m[0] とは書けない**
matrix3 m3 = matrix3(m);
vector row_x = set(1, 0, 0) * m3;
vector row_y = set(0, 1, 0) * m3;

サンプル4 — 2つの回転を混ぜる

関数説明
slerp(a, b, t)クォータニオン同士の補間
// 「今の向き」と「目標の向き」を少しずつ混ぜて追従させる
vector4 cur  = quaternion(dihedral({0,1,0}, normalize(@N)));
vector4 goal = quaternion(dihedral({0,1,0}, normalize(@v)));

float t = chf("follow");            // 0 で今のまま、1 で目標
p@orient = slerp(cur, goal, t);

// 角度と軸から直接作ることもできる
vector4 spin = quaternion(radians(45), {0, 1, 0});
p@orient = qmultiply(p@orient, spin);

サンプル5 — インスタンスの行列を自分で組む

関数説明
instance(pos, dir, scale, up, rot)1発でインスタンス行列を作る
// copytopoints に頼らず、自分で置き場所の行列を作る
vector pos   = @P;
vector dir   = normalize(@v);            // 向ける方向
vector scale = set(1, 1, 1) * @pscale;
vector up    = {0, 1, 0};
vector4 rot  = {0, 0, 0, 1};             // 追加の回転

4@xform = instance(pos, dir, scale, up, rot);

8. 近傍・空間検索

「近くの点を探す」はここです。パーティクルや散らしでよく使います。

pcfilter(h, "Cd")開いた検索の結果を平均で読む
intersect(0, orig, dir)レイを飛ばして当たった位置を得る

xyzdist + primuv の組み合わせを覚えておくと応用が広いです。「相手の面のどこがいちばん近いか」を求めて、そこの属性を読む、という形。

// 相手のジオメトリ(入力1)の、いちばん近い面の色を持ってくる
int   prim;
vector uv;
float d = xyzdist(1, @P, prim, uv);
@Cd     = primuv(1, "Cd", prim, uv);
f@dist  = d;

// 半径内の隣人の平均位置に寄せる（かたまり感を作る）
int pts[] = nearpoints(0, @P, 0.5);
vector sum = 0;
foreach (int p; pts) sum += point(0, "P", p);
if (len(pts) > 0) @P = lerp(@P, sum / len(pts), 0.3);

グループの式に && を書いても期待どおりに絞れません。条件は VEX で1つの属性にまとめてから、グループ側は @rim>0 の1条件で書くのが確実です（実測）。

// 条件をひとつの属性にまとめてから、グループは1条件で書く
float d = dot(normalize(@N), {0,1,0});
i@rim = (d > 0.3 && @P.y > 0.5) ? 1 : 0;
// → blast / group のフィールドには @rim>0 とだけ書く
