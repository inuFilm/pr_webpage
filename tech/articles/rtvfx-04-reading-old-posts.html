リアルタイムVFX 4 — 古い記事を読むための読み替えガイド

realtime-vfx / 2026-08-19

この記事は Real Time VFX を調べてまとめた個人的な学習メモです。 フォーラムの投稿が書かれた時期と、その後に何が変わったかを整理しました。 入門の全体像は第1回の道案内にあります。

この記事の目的

Real Time VFX には10年分の蓄積があり、参照される定番スレッドの多くは 2016〜2018年のものです。長く読まれ続けているだけの価値がある一方で、 ツールやエンジンの記述は現在と食い違っています。

古い記事を捨てる必要はありません。必要なのは読み替えの目安です。 この記事はそのための整理です。

1. フォーラム自身が示している「現在」

推測ではなく、フォーラムの実際の状態を確認しました。 最近投稿されたスレッドのタイトルを見ると、話題の中心がはっきりします。

2026年6月〜8月に投稿されたスレッドを見ると、 Unreal 関連はほぼすべて Niagara についてのものでした。 「Niagara: スケルタルメッシュの頂点カラーでパーティクルを消す」 「Niagara のプレビュータイムラインを再生し直すショートカット」 といった、実務的な質問が並んでいます。

つまりコミュニティの現在地は Niagara にあります。 ところが入門の定番スレッド（2018年）は Cascade を前提に書かれています。ここが最も大きな食い違いです。

2. Unreal — Cascade から Niagara へ

Cascade は Unreal の旧パーティクルエディタです。 2021年にフォーラムで「UE5 で Cascade が消えるのか」という質問が立ち、 返答は端的なものでした。

間違いなくレガシー扱いになるでしょう。

出典: UE5 cascade is dispear?（2021-02）

古い記事に出てくる語いま読むときの扱い
CascadeUnreal の旧パーティクルシステム。UE5 ではレガシー。現在は Niagara
「モジュール」を積む話Niagara にも同様の概念はあるが、構成と名前が異なる。考え方は流用できるが、手順は読み替えが必要
Cascade 前提のチュートリアル「何をやろうとしているか」を読み取り、実装は Niagara の現行ドキュメントで確認する

3. Unity — シェーダーとエフェクトの作り方

2018年の入門スレッドには、Unity 側の補足として Shader Forge（ノードベースでシェーダーを組むアセット）が挙げられています。 「これを使えば UE4 に近いマテリアル制作ができる」という文脈でした。

現在の Unity では、フォーラムの投稿を見るかぎり VFX Graph と Shader Graph が中心です。

VFX Graph を使ったスレッドは2020年以降に多く見られます。

  • Unity VFX Graph study（2020-04）
  • Meteor Rain with Unity VFX Graph (Trigger Events and Trails)（2021-09）
  • Procedural Electricity in Unity VFX Graph!（2022-05）
古い記事に出てくる語いま読むときの扱い
Shader Forgeノードベースのシェーダー作成アセット。現在は Shader Graph が標準的な選択肢
パーティクルシステム全般従来の仕組みに加えて VFX Graph がある。大量のパーティクルを扱う場合に選択肢になります

4. 何が古びて、何が古びないか

ここが読み替えの本質だと思います。

内容扱い
古びないゲームプレイの可読性、造形の原則、タイミングの考え方、仕事の進め方、批評の受け方そのまま読める
ほぼ古びないスクロール＋マスク、メッシュにテクスチャを流す、チャンネルパッキングといった手法の考え方考え方は有効。実装のUIは読み替える
古びるエディタ名、モジュール名、パラメータ名、メニューの場所、アセットの名前現行のドキュメントで確認

言い換えると、「なぜそうするか」は古い記事から読み、 「どのボタンを押すか」は現行のドキュメントで確認する——という分業になります。

5. 古い記事を読むときのチェックリスト

  1. 投稿日を最初に見る。Real Time VFX ではスレッドタイトルの近くに表示されます
  2. 2020年より前なら、エンジンの記述はそのまま信じない
  3. それでも読む価値はある。やろうとしていることの意図を読み取る
  4. 同じ話題で最近のスレッドがないか探す。フォーラムの検索は日付順に並べ替えられます
  5. 実装は現行エンジンのドキュメントで裏を取る

最近の投稿の探し方

Discourse ベースなので、カテゴリごとの新着や検索の並べ替えが使えます。 たとえば Unreal Engine Help（約590トピック）や Unity Help（約250トピック）を新着順で見ると、 いま実際に何が問題になっているかが分かります。
